The Account settings page is where you manage workspace-level details: your workspace name, slug (the identifier used in URLs), and account configuration.

<Callout kind="info">📸 **Screenshot needed:** The Account settings page showing the workspace name and slug fields</Callout>

## Workspace name

Your workspace name appears in the Productised dashboard and in any workspace-level communications. Update it here if your business name changes.

## Workspace slug

The workspace slug is the identifier used in your workspace's URLs (e.g. `app.productised.ai/app/{slug}/...`). The slug is set when the workspace is created. Changing it will update all workspace URLs — if you have shared any workspace-specific links, those will need to be updated.

## Deleting the workspace

Workspace deletion is an irreversible action that removes all products, responses, and settings. If you need to delete your workspace, this action requires confirmation. Ensure you have exported any data you need before proceeding.

If you only want to stop using Productised temporarily, cancel your subscription instead — your workspace and data are retained.
