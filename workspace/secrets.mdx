The workspace Secrets page is where you generate and manage your Productised API key and handle account-level security settings.

<Callout kind="info">📸 **Screenshot needed:** The Workspace Secrets page showing the API key generation section</Callout>

## Your Productised API key

Generate a Productised API key here to authenticate programmatic access to your workspace. The key is shown once at generation — copy it and store it securely.

Use this key for integrations that need to read from or write to your Productised workspace via the API. See the [API documentation](/workspace/api) for available endpoints.

If your key is compromised, regenerate it immediately. The old key is invalidated when a new one is generated.

## Relationship to product-level secrets

This workspace Secrets page manages your Productised API key for the workspace. It is separate from the per-product Secrets tab (in Product Settings), which manages the Anthropic API key used for AI model routing on individual products.

- **Workspace Secrets** — your Productised API key for programmatic access
- **Product Secrets** — your Anthropic API key for BYOK model routing on a specific product
