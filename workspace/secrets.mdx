title: Claude API Key
description: Run your products on your own Anthropic account, for the whole account or one workspace.

**Settings → AI & connections → Claude API Key** is where you add your own Anthropic (Claude) API key. It works on any plan, and only Admins can see it.

## Two places to add a key

- **Account key** — the default for every workspace on the account, whichever Admin saved it.
- **This workspace** card — a key for the workspace you're in, which takes priority over the account key. Switch workspace first to set a key for a different one.

With no key, products run on Productised's key and use your [credits](/workspace/credits).

To get a key, visit [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys). Keys look like `sk-ant-...`, are encrypted before they're stored, and Productised staff can't view them.

## What your key covers

Product conversations and results — the chat and Advisor, AI Agents, scoring, and Standard, Page and Document results — run on your Anthropic account and use no credits. Brain, Build with AI, voice input, AI Insights and Talking Points still run on Productised's services, at no credit cost.

If your key is rejected or runs out of credit, Productised doesn't switch to its own key. Owners and Admins get an alert, and a replaced key works straight away.

## Your Productised API key

Looking for a key to call the Productised API from your own code? That's a different key, created in **Settings → Advanced → API**. See the [API documentation](/workspace/api).
