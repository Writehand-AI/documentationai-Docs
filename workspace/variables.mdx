Variables let you define workspace-level values — **text** or **images** — that you can reference anywhere in your products with the `{{ custom:key }}` syntax. Change the value once, and it updates everywhere it is used.

There are two kinds:

- **Text variables** — reusable values like your booking link, pricing, tagline, or disclaimer.
- **Image variables** — reusable brand assets (logo, headshot, product photos) you upload once and drop into any page. Swap the image here and every page that references it updates automatically.

<Callout kind="info">📸 **Screenshot needed:** The Variables settings page — the Text/Image toggle on the Add Variable form, an image variable showing its thumbnail, and the copy-token chip next to each variable.</Callout>

## What variables are for

Variables solve a specific problem: information (or an image) that appears in multiple products but changes periodically. Your pricing, your booking link, your logo, your headshot. If these are hardcoded into each product, you have to update every one individually. With variables, you update once and every product that references it shows the new value.

They're also useful for content that should stay consistent across products — your brand tagline, your standard disclaimer, your logo — where consistency matters and copy-paste error is a real risk.

## The `{{ custom:key }}` syntax

Reference a variable by wrapping its key in the double-curly-brace syntax:

```
{{ custom:your_variable_key }}
```

For a text variable with key `booking_url` and value `https://calendly.com/yourname/30min`, writing `{{ custom:booking_url }}` renders the full URL. For an **image** variable, the same token resolves to the image's URL — so you can drop it straight into an image tag:

```html
<img src="{{ custom:brand_logo }}" alt="Logo" />
```

This syntax works in:
- Landing pages and output/result pages (built in Claude via the [connector](/claude-connector/overview))
- AI node prompt fields on the canvas (e.g. an AI Agent's instructions)
- Any text field in a product that renders output

<Callout kind="tip">Because Productised pages are real HTML, an image token works **directly** in an `<img src>` — no workaround needed. Change the image in Settings once and every page using `{{ custom:key }}` shows the new one.</Callout>

## Adding a text variable

1. Go to **Workspace Settings → Variables**
2. Leave the type on **Text**
3. Enter a **key** — lowercase letters, numbers, and underscores, no spaces. This is what you type in `{{ custom:key }}`.
4. Enter a **value** — the text rendered wherever the variable is referenced
5. Click **Add**

## Adding an image variable

1. Go to **Workspace Settings → Variables**
2. Switch the type toggle to **Image**
3. Enter a **key** (e.g. `brand_logo`, `founder_headshot`)
4. **Upload your image** — drag-and-drop or pick a file. It's hosted on Productised's CDN and a thumbnail appears.
5. Click **Add**

Now reference it anywhere as `{{ custom:brand_logo }}`. To change the image later, click **Replace** on the variable — every page updates automatically.

## Three ways to grab a token

You never have to memorise a key. There are three places to get the exact token to use:

1. **The Variables page** — every variable has a click-to-copy token chip next to it. Copy `{{ custom:key }}` and paste it wherever you need it.
2. **The canvas** — open a **Page** node and its settings panel lists every variable you can use — custom values, brand images, and the product's form fields — each as a click-to-copy token.
3. **Ask Claude** — in a connector chat, say *"list my custom variables"* and Claude returns every token and image. It sees them through the `get_variables` tool.

## Using your images in Claude-built pages

Productised pages are designed in Claude via the connector. When you ask Claude to build or edit a page, it can **see your uploaded images** (through the `get_variables` tool) and offer them — you don't have to remember the key. Just say *"use my logo in the header"* and Claude drops `{{ custom:brand_logo }}` into the right place.

<Callout kind="note">The connector can't accept a raw file dragged into the Claude chat. To use your own image on a page, upload it here as an image variable first, then reference it — or give Claude a public image URL.</Callout>

## Editing and deleting

Edit a variable's value (or replace its image) any time — the key can't change after creation, since products may reference it. To use a different key, add a new variable. Before deleting, check the key isn't referenced in a live product; a deleted variable's token renders blank.

## Practical examples

| Key | Type | Value | Example use |
|---|---|---|---|
| `brand_logo` | Image | *(uploaded PNG/SVG)* | Header/footer logo across every page |
| `founder_headshot` | Image | *(uploaded photo)* | "About" / trust sections on result pages |
| `booking_url` | Text | `https://calendly.com/yourname/30min` | CTA links on result pages |
| `offer_price` | Text | `£4,500` | Pricing shown on result pages |
| `current_cohort` | Text | `May 2026` | Programme cohort name in onboarding products |
| `standard_disclaimer` | Text | `Results may vary…` | Legal text in commercial outputs |
