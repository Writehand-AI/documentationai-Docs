---
title: How do I add a new project?
description: Learn how to add projects in Productised.
---

## Steps

1. Log into Productised dashboard.
2. Click **Projects** in the sidebar.
3. Select **New Project**.
4. Enter the project name and description.
5. Click **Create**.

## Tip

You can add team members during project creation.

```tip
Projects help you organize all documentation in one place.
```
