The More Tools tab is a growing section of the product settings. It currently shows upcoming features that are in development and will be available in future releases.

## Coming soon

The following tools are in development and will be added to this section when ready:

**Output Types** — additional format options beyond the current Standard, Page and Advisor outcomes, including presentation-style outputs and PDF downloads.

**A/B Testing Tools** — the ability to test different versions of your product against each other to optimise conversion rate or outcome quality.

**Email Integration** — direct connections to popular email marketing platforms so you can trigger automations from product completions without needing a webhook or third-party integration layer.

**API Management** — advanced API configuration and monitoring for products that are integrated into external systems.

These features will appear in this tab as they become available. Check the [changelog](/changelog) for updates.
