The Page SEO tab is where you configure the metadata for your product's public page — the title, description, and images that search engines index and social platforms display when your link is shared. Available on Starter plan and above.

<Callout kind="info">📸 **Screenshot needed:** The Page SEO tab showing the metadata form fields on the left and the search engine preview panel on the right</Callout>

## Why page metadata matters

When someone shares your product link in an email, on LinkedIn, or in a message, the platform fetches the Open Graph tags from your page and constructs a preview card. A well-configured SEO tab means the preview card shows a compelling title, a clear description, and your product image — not a blank card or a technical URL.

For products distributed as lead capture tools, a well-configured social preview can meaningfully increase click-through rates.

## Page tabs

If your product has a landing page and/or an output page, the Page SEO tab shows separate configuration for each. Select the tab for the page you want to configure.

Products that use only an AI Chat node have a single "AI Chat" tab for the chat's public page metadata.

## Metadata fields

**Title** — The page title shown in browser tabs and in search engine results. Defaults to your product name if left blank. Aim for 50–60 characters.

**Description** — The meta description shown below your title in search engine results. Write this as a human-readable summary of what the product offers. Aim for 120–160 characters.

**OG Title** — The title shown in social sharing cards (LinkedIn, Slack, iMessage, etc.). Defaults to the page title if left blank.

**OG Description** — The description shown in social sharing cards. Defaults to the meta description if left blank.

**OG Image** — The image shown in social sharing cards. Recommended size: 1200 × 630px. Defaults to the product thumbnail if left blank.

**Twitter Card** — Defaults to `summary_large_image`, which shows a large image card. Most appropriate for AI products.

**Twitter Title / Twitter Description / Twitter Image** — Overrides specifically for Twitter/X card display. Leave blank to use the OG values.

**Keywords** — Comma-separated keywords for search indexing. Less important for SEO than title and description, but useful for clarity.

**Author** — Optional author name included in the page metadata.

**Canonical URL** — Set if you want to specify a canonical URL different from the product's public URL (for example, if you are embedding the product on your own domain and want the canonical to point there).

**Favicon** — Upload a custom favicon for the product page. Shown in browser tabs.

## Live preview

As you fill in the metadata fields, a live preview shows how your page will appear in search results and in social sharing cards. The search engine preview shows the title and description in standard Google result format. The social media preview shows the OG card with image, title, and description.
