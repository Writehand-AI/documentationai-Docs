title: Visual Insights
description: Visual Insights has been removed from the platform.
---

<Callout kind="warning">
**Visual Insights has been discontinued.** This Power is no longer available on the canvas. If you have an existing product that used Visual Insights, those nodes can be safely removed — your product will continue to function without them.
</Callout>

Visual charts and data visualisations are now handled within the **[Page](/outcomes/assessments)** outcome. You can insert scored results, AI-evaluated metrics, comparison tables, and chart visuals directly into your Page using `{{ }}` variable tokens — see [Design custom result pages](/claude-connector/result-pages).
