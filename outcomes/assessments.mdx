The **Assessment** outcome is a custom HTML result page delivered to your end user at the end of the conversation. Unlike the Standard output — which streams written content directly in the product interface — an Assessment renders at its own URL as a fully designed, branded page.

You design the page entirely in Claude using the [Claude Connector](/claude-connector/overview). Claude writes the HTML, and you use `{{ }}` tokens to pull in the AI Agent's structured outputs, your end user's form answers, and workspace variables — so every page is personalised to that specific person.

---

## What Assessments are for

Assessments are the right outcome when the result needs to feel like a premium, designed deliverable:

- **Scorecards and diagnostics** — a page that displays dimension scores, a radar chart, and colour-coded breakdown bars. The AI Agent produces the numbers; the page renders them visually.
- **Personalised reports** — a multi-section branded report with the end user's name, their situation summary, key findings, and a specific next step.
- **Offer or recommendation pages** — a page that presents a personalised recommendation, tier result, or commercial next step based on what was collected.
- **Assessment results with CTAs** — any deliverable where you want the end user to land on a page that looks and feels like it was built just for them, with a clear action to take next.

Use **Standard** instead when you want to deliver a written output inside the product interface without a separate designed page. Use **Advisor** when you want the AI to continue the conversation interactively after collection.

## How it works

<Steps>
  <Step title="AI Product collects the data" title-type="p">
    Your end user goes through the AI conversation. The AI Product node collects everything it needs — answers, context, nuance.
  </Step>

  <Step title="AI Agent processes and structures it" title-type="p">
    An AI Agent node analyses the collected data and produces structured fields — scores, tier labels, dimension insights, summaries — that the result page will display. You define which fields the agent should output.
  </Step>

  <Step title="The Assessment page renders at a unique URL" title-type="p">
    Each submission generates a unique URL. When your end user lands on it, the `{{ }}` tokens in the page resolve to that person's specific data — their name, their scores, their personalised insights.
  </Step>
</Steps>

## Designing your Assessment page

Assessment pages are designed in Claude via the [Claude Connector](/claude-connector/overview). Tell Claude what kind of page you want and it will write the HTML and wire up the tokens:

> *"Design a scorecard result page for my AI Readiness Assessment. Show an overall score ring, a breakdown bar for each of the five dimensions, and a personalised next-step CTA that links to my strategy call booking page."*

Claude writes the HTML, configures the AI Agent's output fields to match the tokens it used, and saves both with a single call.

### Token syntax

Tokens in Assessment pages use `{{ }}` syntax:

| Token | What it resolves to |
|---|---|
| `{{ object:fieldName }}` | A structured field from the AI Agent (e.g. `{{ object:overall_score }}`) |
| `{{ form:fieldName }}` | A form answer from the conversation (e.g. `{{ form:firstName }}`) |
| `{{ chart:dim1_pct }}` | A computed chart value derived from the agent's dimension scores |
| `{{ custom:key }}` | A workspace variable (e.g. `{{ custom:cta_url }}`) |

See [Token resolution](/claude-connector/tokens) for the full reference.

### Pre-built templates

Productised ships six ready-to-use Assessment templates you can apply in one Claude message:

- **Dimensions** — overall score gauge plus colour-coded bars per dimension
- **Radar Profile** — spider chart across all dimensions
- **Persona** — a named outcome type with defining traits and next steps
- **Deep Insights** — side-by-side strengths and improvement panels
- **Grid Scorecard** — framed layout with a segmented donut and stat cells
- **Narrative Report** — long-form advice with executive summary and pull quotes

> *"Apply the Dimensions template to my Growth Readiness product."*

See [Result page templates](/claude-connector/result-templates) for full descriptions.

## The canvas setup

On the canvas, the Assessment outcome uses the **Page** node (labelled "Page" in the toolbar). A typical Assessment workflow looks like this:

```
AI Product → AI Agent → Page
```

The AI Agent node sits between the AI Product and the Page node because the Agent needs to run first — it analyses the conversation and produces the structured outputs the page tokens reference.

<Callout kind="tip">
  Once the Page node is on your canvas, open the Claude Connector and say "Design a result page for [your product name]." Claude will create the page HTML, configure the AI Agent fields, and link everything together automatically.
</Callout>
