<Callout kind="warning">
  **The Document outcome has been discontinued.** This node type is no longer available on the canvas.
</Callout>

Structured written outputs — action plans, strategy briefs, proposals, personalised guides — are now built using either:

- **[Standard](/outcomes/standard)** — for streamed personalised output delivered inline at the end of the conversation
- **[Page](/canvas/design-node)** — for fully custom HTML layouts you design with Claude, with live tokens for AI outputs and form answers
