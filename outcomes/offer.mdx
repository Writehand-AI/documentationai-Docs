<Callout kind="warning">
  **The Offer outcome has been discontinued.** This node type is no longer available on the canvas.
</Callout>

Commercial outputs — proposals, recommendations, pricing rationale, tailored next steps — are now built using **[Standard](/outcomes/standard)** for inline streamed output, or **[Page](/canvas/design-node)** for fully custom branded layouts.
