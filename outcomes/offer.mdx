title: Offer Outcome
description: The Offer outcome has been removed from the platform.
---

<Callout kind="warning">
**The Offer outcome has been discontinued.** This node type is no longer available on the canvas. If you have an existing product with an Offer node, replace it with a **Document** outcome — both support personalised commercial content including recommendations, CTAs, and next-step framing.
</Callout>

Commercial outputs — proposals, recommendations, pricing rationale, tailored next steps — are now built using the **Document** outcome, which gives you full control over structure and content via the page builder.

See [Document](/outcomes/document) for details.
