Productised ships a native MCP (Model Context Protocol) integration — Anthropic's open standard for connecting Claude to external tools and live data. Once connected, Claude can read your workspace, pull lead data, create products, edit their design, and publish them — all from inside a Claude conversation, without you opening a dashboard.

<Callout kind="info">
**What makes this different from Claude's built-in integrations (Google Drive, Notion, etc.)?** Those are built by Anthropic and give Claude read access to files. The Productised MCP gives Claude *write* access to your actual workspace objects — your products, their AI prompts, their output page HTML, their visibility. Claude can create and fully edit a live AI product conversationally, then give you a shareable preview URL instantly.
</Callout>

---

## What Claude can do

Once connected, Claude gains **16 live tools** against your Productised workspace, organised across four areas:

### Read your workspace

    Full details for a specific product: form questions, workflow structure, and node IDs.

  <Card title="get_responses" icon="inbox">

  </Card>

  </Card>
  <Card title="get_analytics" icon="bar-chart-2">
    Response count, last submission date, 7-day daily trend, and completion rate for any product.
  </Card>
</Columns>

### Create and publish

<Columns cols="2">
  <Card title="create_product" icon="zap">

  </Card>
  <Card title="publish_product" icon="globe">
    Set a product to public and get the live shareable URL — without opening the canvas.

### Edit conversationally

<Columns cols="2">
  <Card title="update_product" icon="edit-2">
    Update the welcome message, button text, button colour, system prompt, background colour, or welcome style — without opening the canvas.
  </Card>
  <Card title="update_node" icon="sliders">
    Patch any canvas node's configuration by node ID or type. Change the system prompt on an AI Chat node, update a node label, or modify any node-level setting.

## The demo URL

Every write operation — `create_product`, `update_product`, `update_node`, `update_page`, `publish_product` — returns a **demo URL** alongside the standard public URL.

The demo URL (`?demo=true`) gives Claude a fully functional, publicly accessible preview of the product that bypasses authentication, domain locks, and submission gates. Claude includes it in every response after a change so you can open the live experience immediately, without logging in.

This is what the whitepaper calls the "Live Preview System" — you describe what you want, Claude makes the change, and you see the result in one click.

## Setup

<Steps>
  <Step title="Get your API key">
    Go to **Settings → API → Keys** in your Productised workspace. Click **Create new key**, give it a name (e.g. "Claude MCP"), and copy the key immediately — it's only shown once.

    <Callout kind="warning">If you lose your key, generate a new one from the same page. Old keys can be revoked at any time.</Callout>
  </Step>
  <Step title="Connect to your Claude client">
    Follow the instructions below for Claude Desktop or Claude.ai — whichever you use.
  </Step>
  <Step title="Test the connection">
    In a new Claude conversation, type: **"List my Productised products"**

    Claude calls `list_products` and returns a live view of your workspace. You'll see a 🔧 tool icon each time Claude makes an MCP call.
  </Step>
</Steps>

---

## Claude Desktop

<Steps>
  <Step title="Open the config file">
    In Claude Desktop, go to **Settings** (⌘,) → **Developer** → **Edit Config**. This opens a JSON file.
  </Step>
  <Step title="Add the Productised server">
    Paste the following, replacing `YOUR_API_KEY` with the key you copied:

    ```json
    {
      "mcpServers": {
        "productised": {
          "url": "https://app.productised.ai/api/mcp",
          "headers": {
            "Authorization": "Bearer YOUR_API_KEY"
          }
        }
      }
    }
    ```

    If you already have other MCP servers in the file, add the `"productised"` block inside the existing `"mcpServers"` object.
  </Step>
  <Step title="Restart Claude Desktop">
    Save the file and restart the app. A 🔌 icon in the chat input confirms the connection is live.
  </Step>
</Steps>

## Claude.ai (browser)

<Steps>
  <Step title="Open Integrations">
    Go to **claude.ai → Settings → Integrations** and click **Add integration**.
  </Step>
  <Step title="Enter the connection details">
    Fill in:
    - **Name:** Productised
    - **URL:** `https://app.productised.ai/api/mcp`
    - **Auth header:** `Authorization: Bearer YOUR_API_KEY`
  </Step>
  <Step title="Save and start a conversation">
    Click Save. Start a new conversation — Claude will now have access to your 16 Productised tools.
  </Step>
</Steps>

## Privacy and security

**Does Claude need my password?**
No. Claude authenticates only via your API key. You control access and can revoke any key at any time from **Settings → API → Keys**.

**What can Claude write or change?**
Claude can create products, update products (name, visibility, AI chat config, individual node config, output page HTML), save Brain ideas, and publish products. It cannot delete products, pages, or responses.

**Is my data sent to Anthropic?**
When Claude uses an MCP tool, the data returned (e.g. your lead list) is included in your conversation context and processed by Anthropic under their standard privacy policy. This is equivalent to copying and pasting that data into Claude yourself.

**Can I see what Claude accessed?**
Yes. Every MCP call is logged in **Settings → API → Logs** with the timestamp, tool name, and result. You have a full audit trail.

## MCP vs other integrations

<Columns cols="3">
  <Card title="MCP (Claude)" icon="cpu">
    Claude talks directly to your workspace — reads data, creates and edits products, publishes, and previews. Best for coaches who work inside Claude and want their full workspace accessible from there.
  </Card>
  <Card title="Zapier" icon="zap">
    Automates what happens after a lead submits — routes data to your CRM, email platform, or spreadsheet. Best for post-response automation with 6,000+ apps.
  </Card>
  <Card title="Webhooks" icon="radio">
    Sends raw response data to any URL. Best for developers building custom workflows or connecting to tools not in Zapier.
  </Card>
</Columns>
