## How integrations work

When someone completes your product, you can push all of the collected data and AI outputs to any external system automatically using a **webhook**.

Webhooks are the primary integration mechanism: Productised sends a real-time POST request to a URL you configure the moment a response is completed. You connect that URL to whichever tool you use — your CRM, Zapier, Make, or your own server.

## Connecting to specific tools

<Columns cols="3">
  <Card title="Webhooks" href="/integrations/webhooks" icon="radio">
    Send raw response data to any URL the moment a conversation completes. Works with any tool that accepts HTTP — your own server, Zapier, Make, or any CRM with a webhook endpoint.
  </Card>
  <Card title="Zapier" href="/integrations/zapier" icon="zap">
    Visual middleware connecting Productised to 6,000+ apps. Best when you need field mapping, filters, or multi-step automation without writing code.
  </Card>
  <Card title="MCP node" href="/powers/connections" icon="share-2">
    Two-way, conversational integration. Add an MCP node to your canvas and Claude can read from and write to your tools during and after conversations — not just push data when complete.
  </Card>
</Columns>

<Callout kind="tip">
  For most use cases — routing leads to a CRM, logging to a sheet, notifying a Slack channel — the webhook + Zapier combination is the quickest setup. Use the MCP node when you need Claude to read data or take actions during the conversation itself, not just at the end.
</Callout>
