## v1.2.0 - 2024-10-15

<Update label="2024-10-15" description="v1.2.0" tags={["feature", "improvement"]}>

## New Features

- Added advanced assessment customization options, including dynamic AI prompts for personalized outcome pages.
- Introduced branded report templates with your logo and brand colors (e.g., `#FED86D`).

## Improvements

- Enhanced AI reasoning for more context-aware lead reports.
- Faster generation of personalized outcomes, reducing wait times by `>50%`.

## Bug Fixes

- Fixed issue with multi-step assessments not saving partial responses.
- Resolved rendering errors in custom outcome pages.

</Update>

## v1.1.0 - 2024-09-20

<Update label="2024-09-20" description="v1.1.0" tags={["bugfix", "improvement"]}>

## Improvements

- Optimized performance for high-traffic assessments, handling `>1000` leads per day.
- Better integration with lead generation tools via webhooks.

## Bug Fixes

- Patched security vulnerability in report generation (no user data exposed).
- Fixed email delivery failures for personalized reports.

## Deprecations

- Legacy static outcome templates deprecated. Migrate to AI-powered dynamic templates.

</Update>

## v1.0.0 - 2024-08-10

<Update label="2024-08-10" description="v1.0.0" tags={["feature", "breaking"]}>

## New Features

- Core AI-powered assessments for lead generation.
- Instant personalized reports and outcome pages.
- No-code builder for quizzes and funnels.

## Breaking Changes

- Initial API structure updated. See migration guide below.

</Update>

## Migration Guide

Follow these steps to update your Productised assessments to the latest version.

<Steps>
  <Step title="Backup Your Data" icon="database">

    Export your current assessments:

````bash
# Via dashboard
# Go to Settings > Export > Download JSON
````

  </Step>
  <Step title="Update Integration" icon="settings">

    Update your webhook URL to `https://api.productised.ai/v2/webhooks`.

    <CodeGroup tabs="JavaScript,Python">
````javascript
// New endpoint
const webhookUrl = 'https://api.productised.ai/v2/webhooks';
fetch(webhookUrl, { method: 'POST', body: JSON.stringify(leadData) });
````
````python
# New endpoint
import requests
webhook_url = 'https://api.productised.ai/v2/webhooks'
requests.post(webhook_url, json=lead_data)
````
    </CodeGroup>

  </Step>
  <Step title="Test Assessments" icon="play">

    Create a test assessment and verify personalized reports generate correctly.

  </Step>
</Steps>

<Expandable title="Detailed Deprecations" default-open="false">

If using deprecated static templates:

1. Open your assessment editor.
2. Switch to "AI Dynamic" mode under Outcomes.
3. Map old fields to new AI prompts, e.g., `{user_responses}` becomes `{lead_context}`.

No downtime expected during migration.

</Expandable>
